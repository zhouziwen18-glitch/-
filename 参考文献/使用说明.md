# 参考文献收录文件夹

把新发表的论文 PDF 放入本文件夹，系统会在启动时自动识别并收录。

## 两种启动方式（任选其一）

**本地预览**（在项目根目录双击 `启动主页.command`，或手动运行）：

```bash
cd 学术主页
npm run build   # 或 npm run dev
```

**线上更新（GitHub Pages）**：把新 PDF 一起提交并推送：

```bash
cd 学术主页
git add -A
git commit -m "feat: 新增论文"
git push origin main
```

## 自动收录机制

每次启动（构建）都会自动扫描本文件夹：

- 识别新增 PDF，自动抽取标题、作者、年份、期刊、DOI（优先 Crossref 权威数据）；
- 将 PDF 复制到 `public/论文/`，并在网页成果列表自动追加展示；
- 已处理过的文件不会重复处理（记录保存在 `.papers-registry.json`，为本地缓存）。

文件名建议（非必须）：`2026-论文标题-作者.pdf`，年份前缀可帮助识别发表年份。
个别论文的期刊分区 / 影响因子若未被自动识别，可在 `src/data/publications.ts` 中补充。

> 本文件夹已纳入 git 仓库跟踪（供 GitHub 自动部署读取）；
> 其中的 `.papers-registry.json` 为本地缓存，已加入 `.gitignore`，不会被提交。
